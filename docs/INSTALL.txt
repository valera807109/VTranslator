VTranslator — установка на Mac
================================

1. Перетащите VTranslator.app в папку «Программы» (Applications).

2. Приложение не подписано сертификатом Apple, поэтому macOS при первом
   запуске его заблокирует. Откройте «Терминал» и выполните одну команду:

       xattr -cr /Applications/VTranslator.app

   После этого запустите VTranslator обычным двойным щелчком.
   (Альтернатива: правый щелчок по приложению → «Открыть» → «Открыть»;
   на macOS 15+ — «Системные настройки → Конфиденциальность и безопасность →
   Всё равно открыть».)

3. Разрешите «Универсальный доступ» (без него не работает перевод
   выделенного текста):
   «Системные настройки → Конфиденциальность и безопасность →
   Универсальный доступ» → включите VTranslator.

4. Значок VTranslator появится в строке меню (вверху справа).
   Щелчок — главное окно, правый щелчок — меню.

Горячие клавиши по умолчанию (меняются в настройках):
   ⌃Q        — перевести выделенный текст во всплывающем окне
   ⌃ ⌃       — то же самое: быстро нажмите Control два раза
   ⌃W        — перевести выделенный текст в главном окне
   ⌃E        — прослушать выделенный текст
   ⌃I        — заменить выделенный текст переводом
   ⌃⇧Q       — выделить область экрана, распознать текст и перевести
   Esc       — закрыть всплывающее окно

ВАЖНО после обновления на новую версию: если горячие клавиши перестали
получать выделенный текст — в «Универсальном доступе» удалите VTranslator
кнопкой «–» и добавьте заново (или выключите и включите переключатель).

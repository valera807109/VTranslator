# VTranslator

Быстрый переводчик для macOS в духе QTranslate: живёт в строке меню и переводит выделенный текст в любом приложении по горячей клавише.

## Возможности

- **Перевод выделенного текста** во всплывающем окне рядом с курсором (`⌃Q` или двойное нажатие `⌃`).
- **Главное окно**: исходный текст и перевод, выбор языков, обмен языков местами, автоперевод во время набора (`⌘↩` — перевести сразу).
- **Два сервиса** через неофициальные адреса (без ключей API):
  - Google Переводчик — `translate.googleapis.com` (client=gtx): перевод, словарь с частями речи и обратными переводами, транслитерация;
  - Яндекс Переводчик — `translate.yandex.net` (API мобильного приложения): перевод и транслитерация.
- **Умное переключение языков**: если язык текста совпал с языком перевода, текст переводится на второй язык (RU ↔ EN без ручного переключения).
- **Замена выделенного текста переводом** (`⌃I`).
- **Озвучка** исходного текста и перевода (Google TTS или системный голос), `⌃E` озвучивает выделенный текст.
- **Распознавание текста с экрана (OCR)** с переводом (`⌃⇧Q`) — встроенный в macOS Vision, работает офлайн.
- **Обратный перевод**, копирование, перевод буфера обмена.
- **История переводов** с поиском и листанием ◀ ▶ в главном окне.
- **Режим мыши**: после выделения текста мышью рядом появляется значок перевода.
- **Исключения**: приложения, в которых горячие клавиши не срабатывают.
- Настраиваемые горячие клавиши, размеры шрифтов, автозапуск, значок в Dock.

## Сборка

Сборка выполняется в GitHub Actions (`.github/workflows/build.yml`) на macOS:

1. Залейте проект в репозиторий GitHub (ветка `main`).
2. Откройте вкладку **Actions** → последний запуск **Build macOS app** → внизу раздел **Artifacts** → скачайте `VTranslator-…` (внутри `.dmg` и `.zip`).
3. Для выпуска релиза создайте тег: `git tag v1.0.0 && git push --tags` — файлы появятся в разделе **Releases**.

Локально на Mac: `bash scripts/bundle.sh` (нужен Xcode или Command Line Tools, Swift 5.9+). Результат — в папке `dist/`.

## Установка

Одной командой в «Терминале» (без предупреждений macOS, ею же обновляется):

```bash
curl -fsSL https://raw.githubusercontent.com/valera807109/VTranslator/main/scripts/install.sh | bash
```

Или вручную из `.dmg` — см. [docs/INSTALL.txt](docs/INSTALL.txt). После установки разрешите «Универсальный доступ».

## Требования

macOS 13 Ventura или новее, Apple Silicon или Intel (универсальная сборка).

## Структура

```
Sources/VTranslator/
  EntryPoint.swift, AppDelegate.swift   — запуск, строка меню, обработка горячих клавиш, окна
  Engines/   — Google и Яндекс (неофициальные адреса), разбиение длинного текста
  Core/      — настройки, горячие клавиши (Carbon), выделенный текст (Accessibility/⌘C),
               двойное нажатие, режим мыши, озвучка, OCR, история
  UI/        — главное окно, всплывающее окно, история, настройки (SwiftUI)
scripts/     — упаковка .app/.dmg и генерация иконки
```
